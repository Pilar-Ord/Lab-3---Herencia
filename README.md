# Lab-3---Herencia
Nombre Completo: María del Pilar Ordóñez Helton Carné: 26360

Descripción
EnvíaGT es un programa de consola en Java para gestionar envíos de una empresa de mensajería. Permite cotizar y registrar sobres, paquetes normales, paquetes frágiles y cargas refrigeradas. Cada categoría calcula su costo, tiempo estimado de entrega y número máximo de intentos según sus propias reglas. La clase Cliente conserva los datos del remitente.

Cómo ejecutar
javac -d bin src/*.java
java -cp bin Main
